# Simple Interest Calculator

This project is a simple Bash script based calculator that computes 
simple interest based on user-provided principal amount, rate of 
interest, and time period.

## Features
- Takes user input for principal, rate, and time
- Calculates simple interest using the formula: SI = (P × R × T) / 100
- Displays the result to the user

## How to Run
```bash
bash simple-interest.sh
```
